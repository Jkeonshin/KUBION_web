# KUBION (국비온)

**국비 지원 교육을 더 쉽게, 더 정확하게.**  
KUBION은 국비 교육 정보를 한 곳에 모아 **비교·추천·후기·커뮤니티를 제공**하는 **실전형 국비 매칭 플랫폼**입니다.

---

## 🚀 서비스 소개

국비 지원 과정은 많지만,
- 어디에 어떤 과정이 있는지 찾기 어렵고
- 홍보 정보와 실제 후기의 신뢰도가 낮으며
- 본인에게 맞는 과정을 **스스로 판단하기 어렵다**는 문제가 존재합니다.

KUBION은 이를 해결합니다.

**KUBION 핵심 기능**
| 기능 | 설명 |
|---|---|
| 개인 맞춤 국비 과정 추천 | 관심 분야 / 목표 / 위치 기반으로 프로그램을 추천 |
| 실수강생 리뷰 데이터베이스 | 실제 수강 경험, 취업 연계 결과, 과정 난이도 정보 제공 |
| 지역/학교/기관 커뮤니티 | 학습/취업 관련 노하우 공유 |
| 과정 비교 도구 | 커리큘럼 / 기관 신뢰도 / 후속 진로 등을 한 눈에 비교 |

---

## 🎯 대상 사용자 (Persona)

| 사용자 | 니즈 | KUBION 해결 방식 |
|---|---|---|
| 국비 수강 희망자 | 나에게 맞는 과정 선택 | 맞춤 추천 + 실제 후기 + 비교 기능 |
| 국비 교육기관 | 효율적인 홍보 & 수강생 확보 | 기관 관리 페이지 + 이용자 데이터 기반 노출 |
| 취업 준비생 / 경력 전환자 | 방향성 + 기술 학습 | 로드맵 / 커리큘럼 가이드 / 커뮤니티 |

---

## 🌱 서비스 가치 (Value Proposition)

- **정보의 불균형 해소**  
  흩어진 국비 정보를 **명확하게 정리**하여 제공
- **신뢰 기반 의사결정**  
  광고 중심이 아닌 **실수강생 검증 데이터** 중심
- **진짜 도움이 되는 네트워크 형성**  
  국비생들이 서로 **연결되고 성장하는 커뮤니티**
